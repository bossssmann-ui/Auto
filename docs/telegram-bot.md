# 🤖 Telegram-бот — Руководство по запуску

## Предварительные требования

- **Node.js** версии 18 или выше
- **npm** (идёт в комплекте с Node.js)
- **Токен Telegram-бота** — получите его у [@BotFather](https://t.me/BotFather) в Telegram

## 1. Установка зависимостей

В корне проекта выполните:

```bash
npm install
```

> Пакет `telegraf` уже включён в зависимости проекта (`package.json`) и будет установлен автоматически.

## 2. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` (если ещё не сделали) и добавьте токен бота:

```bash
cp .env.example .env
```

Откройте `.env` и укажите значение:

```
AI_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
```

> Замените на настоящий токен, полученный от @BotFather.

## 3. Запуск бота

```bash
npx tsx server/bot.ts
```

При успешном запуске в терминале появится:

```
🤖 Бот запущен и слушает сообщения...
```

Теперь откройте Telegram, найдите вашего бота и нажмите **Start** (или отправьте `/start`).

## 4. Остановка бота

Нажмите `Ctrl+C` в терминале — бот корректно завершит работу благодаря обработке сигналов `SIGINT`/`SIGTERM`.

## Структура файла `server/bot.ts`

| Функция | Описание |
|---------|----------|
| `/start` | Приветствие пользователя |
| Обработка текста | Эхо — повторяет текст пользователя (заглушка для будущей интеграции с AI) |
| Обработка ошибок | Логирование ошибок без падения бота |
| Graceful shutdown | Безопасная остановка по `SIGINT`/`SIGTERM` |

## Что дальше?
