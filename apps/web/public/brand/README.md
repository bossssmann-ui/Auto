# Бренд-ассеты SpecTechMash — что сюда положить

Финального логотипа пока нет (PROJECT_PLAN P4-03). Когда он будет готов,
файлы кладутся в эту папку, подключение — точечное, без ломки layout.

## Ожидаемые файлы

| Файл | Формат | Назначение | Куда подключать |
|---|---|---|---|
| `logo.svg` | SVG, горизонтальный, читаемый на светлом фоне | Header/Footer | `components/Shell/BrandMark.tsx` (заменить текстовый wordmark на `next/image`) |
| `logo-dark.svg` | SVG для тёмной темы | Header/Footer (dark mode) | там же, через CSS/`prefers-color-scheme` |
| `icon.svg` | Квадратный знак | favicon-набор | `app/` (Next file-convention `icon.svg`) |
| `og-logo.png` | PNG ≥ 400×400, непрозрачный фон | Динамические OG-картинки | `app/og/route.tsx` |

## Требования

- Русский дубль: рядом с латиницей `SpecTechMash` в публичных материалах
  должно оставаться «Спецтехмаш» (53-ФЗ, до регистрации ТЗ).
- Никаких ассетов Pacific Star / «Тихоокеанская Звезда» — это другой бренд
  и другое юрлицо.
- SVG — оптимизированный (svgo), без внешних шрифтов внутри файла.
